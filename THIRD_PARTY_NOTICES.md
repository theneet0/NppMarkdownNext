# Bearded Theme palettes

The Bearded palettes originate from [BeardedBear/bearded-theme](https://github.com/BeardedBear/bearded-theme), licensed under GPL-3.0.

The Gold D Raynh Markdown roles use version 10.1.0, commit `23e830fb0889d66d837a73cfe56d8af83cdfccdf`, and the author's editor token scopes. The imported Gold JSON has SHA-256 `7ca6626ae8b4e3c7fbd59ab775f5a177db94fe048ec130ab64f0191c2d58917c`.

The reader intentionally overrides Gold's bold-text color with cool white (`#edf2f7`). The original editor role remains in `markdown`; the reader adaptation is recorded separately in `markdownOverrides` and shared by preview and HTML export.

The other palettes retain the previously integrated Zed-export values. Stable identifiers and labels are preserved in `themes/reader-themes.json`; generation is offline and does not require VS Code.

Original author: BeardedBear and the Bearded Theme contributors. The original license is included in `themes/BEARDED_LICENSE`.
